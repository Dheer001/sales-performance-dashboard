# Sales Performance Dashboard — Microsoft Excel

An interactive Sales Performance Dashboard built in Microsoft Excel to analyze sales, profitability, order performance, and business trends across multiple dimensions.

## Project Overview

This project analyzes sales transaction data and converts raw data into meaningful business insights using Microsoft Excel.

The dashboard provides an overview of sales and profitability while allowing performance to be examined across different business dimensions such as region, city, customer segment, product category, sales channel, salesperson, and time period.

## Objectives

- Analyze overall sales and profit performance
- Identify sales trends across different months and years
- Compare performance across regions and cities
- Analyze product category and customer segment performance
- Evaluate sales channel and salesperson performance
- Create KPI-based summaries for business performance monitoring
- Transform raw transactional data into an interactive dashboard

## Dataset

The dataset contains **1,500+ sales transactions** covering sales activity across:

- Regions
- Cities
- Customer Segments
- Product Categories
- Sales Channels
- Salespersons
- Order Dates
- Sales Revenue
- Profit/Loss

The analysis covers data from **2024–2025**.
